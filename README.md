# Centro de Control de Sondas Espaciales
Aplicación web concebida como centro de control para la gestión y monitorización de sondas espaciales.

Objetivo del proyecto

El objetivo principal de este proyecto es aprender y pulir mis habilidades en Angular mediante el desarrollo práctico de una aplicación temática y estructurada, avanzando desde la base inicial del framework hasta funcionalidades más completas de control y visualización.

Tecnologías que vais a utilizar

Angular (estructura inicial por defecto generada con Angular CLI, TypeScript, HTML y CSS/SCSS).

(A medida que avance el desarrollo se podrán ir incorporando librerías, estilos o herramientas adicionales según las necesidades del centro de control).

Alcance inicial

En esta primera fase del proyecto se contempla:

Creación y configuración de la estructura inicial por defecto de Angular.

Preparación del entorno de trabajo y organización base del repositorio.

Definición de la estructura general y primeras vistas/componentes iniciales del centro de control de sondas espaciales.
